Security checks performed on every file
  • Extension blocklist — .exe, .bat, .cmd, .sh, .ps1, .jar, .class, macro-enabled Office files, and more are rejected.
  • MIME type allowlist — only known-safe MIME types (PDF, images, video, audio, plain documents) are accepted.
  • Magic bytes scan — the first 8 bytes of every file are read to detect executables and scripts disguised with a safe extension.
  • Double extension check — files like invoice.pdf.exe are rejected.
  • Null-byte injection — filenames containing null characters are rejected.
  • File size limit — empty files and files above 5 GB are rejected.
